# V0.3 规则 Schema Prompt

给其它 Agent 的系统提示。一篇文章抽出若干条规则；每条规则包含节点定义，以及该节点与其他规则节点的关系。

| | |
|---|---|
| Prompt 全文 | `work/server-v0.3-review/data/prompts/market_rule_schema_types.prompt.md` |
| JSON Schema | `work/server-v0.3-review/data/knowledge_graph/schemas/prompt/LearnedRules.schema.json` |
| CLI 登记 | [v0.3-cli.md](v0.3-cli.md) |

类型：`MarketRule`（一条规则）= `MarketNode` + `RuleRelation[]`。输出 `{ "rules": [...] }`。
