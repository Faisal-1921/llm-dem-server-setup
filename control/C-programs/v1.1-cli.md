# V1.1 CLI：入口、出口、功能

工作目录必须是 V1.1 项目根。用户入口只有测试编号和 `control-ui`：

```bash
python run.py T14
python run.py T14 --real-api
python run.py T14 --real-api --rounds 100
python run.py test T11 T14
python run.py test --real-api --rounds 3
python run.py control-ui
```

`lem_dem/cli.py` 按 `ENABLED_TESTS` / 命令行 Txx 启动 `tests/.../Txx.py`。退出码：成功 0；未知命令 2；测试走 unittest 返回码。

默认证明轮次 `--rounds 3`。百轮接口：`--rounds 100`（T06 / T15 池 / T16 池用 105）。

公共输入在 `data/`。测试产物在 `runtime/test-results/Txx_*/`。本机镜像多在 `outputs/`。

旧实验名（`map`、`dynamic-components` 等）默认拒绝。隐藏开关：`python run.py --legacy map` 转发到对应 Txx。

索引：项目内 `tests/TEST_INDEX.md`；真实 API：`docs/tests/REAL_API.md`。

## control-ui

| | |
|---|---|
| 功能 | 只读 HTML：`run.py Txx` → `Txx.py` → `lem_dem/`；点击节点显示公开函数 Markdown |
| 入口 | `control_UI/server.py` |
| HTTP 出口 | `http://127.0.0.1:8767`（禁止 8765/8766；本机需独立 SSH 隧道） |
| 隧道 | `work/v1.1-control-ui-tunnel.sock` |

与监视器（8765）和 V0.3 知识图谱（8766）分开。接口见 [A-server-interfaces/control-ui.md](../A-server-interfaces/control-ui.md)。

```bash
python run.py control-ui
```

## 任务到文件（摘要）

更全的表见项目内 `docs/file-map.md`。

| 任务 | 实现 | 跑法 |
|---|---|---|
| 文本归一化 | `lem_dem/mapping.py`、`models/unit.py`、`terminology.py` | `python run.py T01` |
| 全流程 | `full_process.py`、`mapping_repair.py` | `python run.py T09` |

| 规则 IR | `models/operation_rule.py`、`rule_agent.py`、`optimization/rule_modules.py` | `python run.py T11`–`T14` |
| 长实验编排 | `lem_dem/experiments/`（库函数，不是用户命令） | 对应 Txx |
